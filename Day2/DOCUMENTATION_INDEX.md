## Quick Reference

### Start Command
```bash
npm install && npm run dev:full
```

### Access
```
Frontend: http://localhost:5173
Backend: http://localhost:3001
```

### Key Endpoints
```
GET  /api/actors
POST /api/actors/search
POST /api/actors/:id/execute
```

### Search Examples
- "web scraper"
- "instagram"
- "amazon"
- "youtube"

- DATA_EXTRACTION
- SOCIAL_MEDIA
- ECOMMERCE
- AUTOMATION
