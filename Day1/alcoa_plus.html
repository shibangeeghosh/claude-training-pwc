What is ALCOA+?

ALCOA+ is the industry standard for data integrity in regulated environments, particularly in pharmaceutical operations. It ensures that all data generated, recorded, and maintained meets strict quality and compliance requirements.

ALCOA+ consists of five core principles (ALCOA) plus four additional dimensions (+) that together create a comprehensive data integrity framework.

✍️ Attributable CORE

"Who did what, when, and why?"

Every action, data entry, and modification must be traceable to the individual who performed it, with clear identification of timing and reason.

Key Practices:
  • User identification and authentication
  • Electronic signatures (eSignatures)
  • Timestamps for all entries
  • Audit trails documenting changes

📖 Legible CORE

"Can it be read and understood?"

All data must be clear, readable, and understandable. Handwritten entries should be legible; electronic data must be in accessible formats.

Key Practices:
  • Clear handwriting or printed text
  • Standard units and terminology
  • Proper formatting and labeling
  • Accessible file formats

⏰ Contemporaneous CORE

"Was it recorded at the time of the event?"

Data must be recorded at the time an activity occurs, not retrospectively or reconstructed later.

Key Practices:
  • Real-time data entry
  • Synchronization with activities
  • No backdating or delayed entries
  • Immediate documentation of events

📋 Original CORE

"Is this the first, official record?"

Data should exist in its original, first-recorded form. Copies must be clearly identified as such.

Key Practices:
  • Preserve original records
  • Document data copies and transfers
  • Maintain data lineage
  • Archive original media safely

✓ Accurate CORE

"Is the data correct and true?"

All data must be accurate, complete, and reflect actual events or measurements with no errors or omissions.

Key Practices:
  • Data validation and verification
  • Calibration of instruments
  • Quality control checks
  • Error correction procedures

✅ Complete PLUS

"Is all relevant data included?"

All required data elements must be present. No omissions of relevant information, even if seemingly minor.

Key Practices:
  • Complete data entry forms
  • No missing fields or sections
  • Documentation of all relevant events
  • Traceability of all components

🔗 Consistent PLUS

"Does it align across all records?"

Data must be consistent across all systems, records, and documents with no contradictions or discrepancies.

Key Practices:
  • System reconciliation
  • Standardized procedures
  • Cross-reference verification
  • Unified data standards

⏳ Enduring PLUS

"Will it survive the test of time?"

Data must be stored and preserved in a way that ensures it remains accessible and unchanged throughout its required retention period.

Key Practices:
  • Proper data storage
  • Backup and recovery procedures
  • Defined retention schedules
  • Migration for format obsolescence

🔍 Available PLUS

"Can it be retrieved when needed?"

Data must be readily retrievable and accessible to authorized personnel for review, audit, or investigation purposes.

Key Practices:
  • Organized filing systems
  • Access controls and permissions
  • Quick retrieval capabilities
  • Regulatory inspection readiness
